#+title: Awesome X11

A lightly-curated list of resources for X11.

* Window Managers

- [[https://github.com/bradleythughes/blackbox][Blackbox]], a minimalistic window manager
- [[https://dowm.softwarespot.top/][DoWM]], a beautiful tiling and floating window manager
  - [[https://github.com/BobdaProgrammer/doWM][GitHub repo]]
- [[https://github.com/driusan/dewm][Dewm]], an autotiling window manager written in Go, in a literate programming
  style
- [[https://www.fvwm.org/][FVWM]], the F? Virtual Display Manager
- [[https://codeberg.org/museoa/hackedbox][Hackedbox]], the bastard son of Blackbox
- [[https://ice-wm.org/][IceWM]], an easy and simple window manager
  - [[https://github.com/ice-wm/icewm/][GitHub repo]]
- [[https://github.com/marshallmason/ittywm][Ittywm]], another tiny window manager
- [[https://github.com/janbina/swm][Janbina SWM]], minimal window manager written in Go
- [[https://github.com/thomasysliu/node-wm/][Node-WM]], a NodeJS-based window manager
- [[https://openbox.org/][Openbox]], a minimalistic, configurable window manager
  - [[git://git.openbox.org/mikachu/openbox][Git repo]]
- [[https://github.com/duckinator/possum-wm][Possum WM]], keyboard-driven window manager for palmpc-type devices
- [[https://sawfish.tuxfamily.org/][Sawfish]], a window manager hackable in a Lisp dialect
  - [[https://github.com/SawfishWM][GitHub org]]
- [[https://www.giannone.eu/skatoswm/][SkatOSWM]], very small window manager which centers all new windows on the
  screen
- [[http://swm.sourceforge.net/][SWM]], small window manager
- [[https://github.com/adamnew123456/SmallWM][SmallWM]], Xlib window manager inspired by TinyWM
- [[http://incise.org/tinywm.html][TinyWM]], the reference implementation for a tiny X11 window manager
  - [[https://github.com/mackstann/tinywm][GitHub repo]]
- [[https://git.sr.ht/~tomtom/tinywm-go-x11][TinyWM-Go]], a TinyWM written in Go
- [[https://github.com/stefanbidi/tinywm-xcb][TinyWM-XCB]], a port of TinyWM using libxcb
- [[http://incise.org/whimsy.html][Whimsy]], a small window manager written entirely in Python
  - [[https://github.com/mackstann/whimsy/][GitHub repo]]
- [[https://www.windowmaker.org/][WindowMaker]], a window manager that emulates NEXTSTEP look and feel
  - [[https://repo.or.cz/wmaker-crm.git][Git repo]]
  - [[https://github.com/window-maker/wmaker][GitHub mirror]]
- [[https://github.com/BurntSushi/wingo][Wingo]], a window manager written in Go
- [[https://github.com/Zamony/wmwm][Wmwm]], a window manager fully written in Go
- [[https://github.com/mcpcpc/xwm][Xwm]], a tiny floating window manager using XCB
- [[https://github.com/yazeed1s/zwm][Zwm]], a minimalistic window manager written in C

* Desktop Environments

- [[https://sourceforge.net/p/cdesktopenv/wiki/Home/][Common Desktop Environment]], an oldschool desktop environment
- [[https://www.enlightenment.org/][Enlightenment]], an elegant desktop environment
- [[https://github.com/gershwin-desktop/gershwin-desktop][Gershwin Desktop]], OSX-like desktop environment exclusive in [[https://www.ghostbsd.org/][GhostBSD]]
- [[https://mate-desktop.org/][MATE]], a fork/continuation of [[https://www.gnome.org/][GNOME]] 2 series
- [[https://www.bodhilinux.com/moksha-desktop/][Moksha Desktop]], a fork from Enlightenment DR17
  - [[https://github.com/JeffHoogland/moksha][GitHub repo]]
- [[https://www.trinitydesktop.org/][Trinity Desktop]], a fork from [[https://kde.org/][KDE]] 3.x series
- [[http://www.xfce.org][XFCE]], a lightweight desktop environment

* Applications

- [[https://conky.cc/][Conky]], lightweight system monitor
  - [[https://github.com/brndnmtthws/conky][GitHub repo]]
- [[http://aanatoly.github.io/fbpanel/][Fbpanel]], lightweight desktop panel
- [[https://nsxiv.codeberg.page/][Nsxiv]], Neo Simple X Image Viewer
  - [[https://codeberg.org/nsxiv/nsxiv][Codeberg repo]]
- [[https://picom.app/][Picom]], a compositor for X11
  - [[https://github.com/yshui/picom][GitHub repo]]
- [[https://codeberg.org/itszariep/sglogout][SGLogout]], a logout menu
- [[https://itn-web.it.liu.se/~stegu76/xteddy/][XTeddy]], a Teddy Bear!
  - [[https://codeberg.org/museoa/xteddy][Codeberg/Museoa mirror]]

* Libraries

- [[https://www.sminez.dev/penrose/][Penrose]], a Rust library for writing X11 window managers
  - [[https://github.com/sminez/penrose][GitHub repo]]
- [[https://codeberg.org/itszariep/sgxpos][SGXPos]], Simple GTK X11 Positioning library

* Implementations

- [[https://github.com/ghaerr/microwindows][Microwindows]], also called Nano-X, small graphical windowing system that
  implements both Win32 and Nano-X (X11-like) APIs for clipped graphics drawing
  in windows
- [[https://github.com/PerikiyoXD/rxserver/][RXServer]], an experimental implementation in Rust
- [[https://github.com/tinycorelinux/tinyx][tinyX]], a tiny implementation
- [[https://github.com/marchaesen/vcxsrv][vcxsrv]], a Windows X server based on XOrg
- [[https://www.xfree86.org/][XFree86]], a historic reference implementation for Unix-like systems
- [[https://www.x.org/wiki/][XOrg]], the top-of-mind reference implementation for Unix-like systems
  - [[https://www.xquartz.org/][XQuartz]], an effort to build XOrg in MacOS
- [[https://xenocara.org/][Xenocara]], an infrastructure to build XOrg, kept by [[https://www.openbsd.org/][OpenBSD]] project
  - [[https://github.com/openbsd/xenocara][GitHub mirror]] from [[https://cvsweb.openbsd.org/xenocara/][official CVS repo]]

- [[https://x11libre.net/][XLibre]], a hard fork from XOrg aiming to provide a more actively maintained and
  modernized alternative to the aging X11 system
  - [[https://github.com/X11Libre/xserver][GitHub repo]]

* Misc Links and Articles

- [[https://xteddy.org/xwinman/][Window Managers for X]], a site containing a truckload of info about X
- [[https://asterisk.dynevor.org/xfree-forked.html][The XFree / X.Org fork and open source governance]]
